## 2. Доработка индивидуального проекта

Исходный проект ПР1 предварительно сохранён в отдельной папке с историей Git
и в ZIP-архиве. Его сценарий доработан в основном репозитории. Три функции
проверки условий назначения сохранены в `rules.py`.

Проекты, руководители и назначения представлены списками словарей.
Реализованы добавление, поиск, подбор по специализации и загрузке,
сортировка, создание и отмена назначений, вывод списков и истории.
Координатор подтверждает операции назначения и отмены.
Загрузка вычисляется по действующим назначениям, отменённые записи
сохраняются в истории и не занимают место в лимите.

Код разделён на `main.py`, `projects.py`, `managers.py`, `assignments.py`,
`rules.py`, `utils.py`, `data_types.py`, `validation.py` и `storage.py`.
Основные функции имеют docstring и аннотации типов.

Данные хранятся в `data/app_data.json`: три коллекции связываются числовыми
ID, даты представлены строками ISO. Изменения сохраняются после каждой
успешной операции. Программа обрабатывает некорректный ввод, отсутствующие
ID, повреждённый JSON и ошибки записи, не перезаписывая прежние данные.
