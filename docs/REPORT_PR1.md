## 2. Индивидуальный проект

Разработана начальная версия сервиса назначения руководителей проекта.
Пользователем является координатор, который выбирает кандидата с учётом
специализации и текущей загрузки.

В `main.py` реализованы три функции: сравнение специализаций, проверка
свободного места и определение причины отказа в назначении. При успешной
проверке и подтверждении координатора проекту назначается руководитель,
а его загрузка увеличивается на один проект. При нарушении ограничений
выводится причина отказа. Данные представлены простыми переменными;
сохранение между запусками на этапе ПР1 не выполняется.
