# ПР2 Подготовка к запуску и защите

## Что подготовлено

Тема № 495 «Сервис назначения руководителей проекта».
Одна консольная программа с 11 действиями меню и выходом, три коллекции,
JSON-хранилище, функции с аннотациями типов и 48 автоматических тестов.
Собственные классы появятся в ПР3.

## Демонстрация на копии данных

Проверьте, что файл `data/practice.json` ещё не используется для нужных вам
данных. Скопируйте в него учебный JSON и запустите отдельное хранилище:

```powershell
Copy-Item data/app_data.json data/practice.json
.\.venv\Scripts\python.exe main.py --data data/practice.json
```

2. Пункт 10, проект 1: подходят Анна Смирнова и Мария Соколова.
3. Пункт 6, проект 1, руководитель 1, ответ `да`: создаётся назначение № 3.
4. Пункт 2: загрузка Анны становится 3/3.
5. Повторное назначение проекта 1 отклоняется: у проекта уже есть руководитель.
6. Пункт 7, назначение 3, ответ `да`: запись отменяется, загрузка снова 2/3.
7. Пункт 3: отменённая запись остаётся в истории.
8. Завершите программу пунктом 0 и откройте то же хранилище повторно.
   Списки и отмена должны сохраниться.
9. Проверьте добавление проекта и руководителя, поиск, сортировку, неверные ID

Не копируйте учебный JSON поверх своих настоящих записей.

## Отладка в VS Code

1. Откройте папку проекта и выберите интерпретатор `.venv\Scripts\python.exe`.
2. В `assignments.py` поставьте точку останова в `get_manager_load()`.
3. Нажмите F5. В меню выберите 2 или 6.
4. Покажите аргументы `manager_id` и `assignments`. Для ID 1 в учебном
   хранилище есть две действующие записи.
5. Шаг F10 выполняет подсчёт; функция возвращает число 2.
6. В `rules.py` проверьте `has_free_capacity(2, 3)`: результат `True`.
7. После назначения загрузка становится 3. При лимите 3 условие `<`
   возвращает `False`: назначать четвёртый проект нельзя.

Учебная ошибка: временно замените `<` на `<=` в `has_free_capacity()`.
Покажите, почему сравнение 3 и 3 ошибочно разрешает ещё одно назначение.
Верните `<` и повторите тесты. Не сохраняйте учебную ошибку в Git.

## Где использованы темы ПР2

| Тема | Пример в проекте |
| --- | --- |
| Списки и словари | Коллекции проектов, руководителей и назначений. |
| Циклы | Цикл меню `while`, вывод и проверки `for`. |
| Функции и модули | `projects.py`, `managers.py`, `assignments.py`, `storage.py`. |
| Обработка исключений | Неверные числа, отсутствующие ID, JSON и ошибки записи. |
| Файлы и `with` | Чтение JSON и запись временного файла в `storage.py`. |
| Аннотации типов | Параметры и результаты основных функций. |
| Генераторы | Подсчёт загрузки `sum(...)` и поиск записи `next(...)`. |
| Списковые включения | Поиск и отбор кандидатов. |
| Множества | Контроль уникальности ID и действующих назначений. |
| Lambda | Ключ сортировки руководителей по загрузке, имени и ID. |
| Интроспекция | На защите можно показать `help(create_assignment)` или `.__doc__`. |
| Pytest | Правила, коллекции, файлы и сквозные сценарии меню. |

Интроспекция используется при изучении кода, не вынесена отдельным пунктом
пользовательского меню. Декораторы в основном коде ПР2 не требуются.
`@pytest.fixture` в тестах задаёт тестовые данные; изучение декораторов
прикладного кода относится к ПР3.

## Основные ответы по своему проекту

- ПР1 сохранён: его три функции перенесены в `rules.py`, а одиночный пример
  представлен связанными записями коллекций.
- В JSON находятся данные, а не экземпляры пользовательских классов.
- ID связывают назначение с проектом и руководителем.
- Загрузка равна числу назначений с `is_cancelled == False`.
- Отмена не удаляет историю; поэтому ID отменённых записей не используются снова.
- Повреждённый JSON не заменяется пустыми коллекциями: программа завершает
  запуск с сообщением, оставляя файл для исправления.
- При отсутствии файла допускается создать новое пустое хранилище.
- Проверка данных выполняется и при загрузке, и перед записью.
- Единый JSON позволяет сохранить все три связанные коллекции целиком.
- При ошибке сохранения не принимаются ни новые данные в памяти, ни частичная запись.

Полный список контрольных вопросов находится на страницах 30–32 методички ПР2.
