## Как запустить

Откройте в VS Code именно каталог `project-lead-assignment`. В терминале:

```powershell
.\.venv\Scripts\python.exe main.py
```

При ответе `да` программа назначает Анну Смирнову и увеличивает загрузку
с 2 до 3. При ответе `нет` назначение отменяется.

## Отладка в VS Code

Нужны расширения Python и Python Debugger. На текущем компьютере их каталоги
обнаружены; конфигурация запуска сохранена в `.vscode/launch.json`.

1. Выберите `.venv\Scripts\python.exe` через команду
   `Python: Select Interpreter`.
2. Откройте `main.py` и поставьте breakpoint на строку
   `return 0 <= current_load < project_limit`.
3. Нажмите F5 и выберите «ПР1: назначение руководителя».
4. В панели переменных проверьте `current_load == 2` и `project_limit == 3`.
5. Выполните шаг F10. Вызов возвращает `True`, назначение разрешено.
6. Продолжите F5 и в терминале подтвердите операцию ответом `да`.

Вторая полезная точка останова — строка `current_load += 1`.
До её выполнения загрузка равна 2, после шага F10 — 3.

## Учебная ошибка для демонстрации

Проверяется граница загрузки: руководителю с тремя проектами при лимите
три нельзя добавлять четвёртый.

1. В `main()` временно установите `current_load = 3`.
2. Запустите правильный код: ожидается сообщение
   «Назначение невозможно: Достигнут лимит проектов руководителя».
3. В `has_free_capacity()` временно замените `<` на `<=`:

   ```python
   return 0 <= current_load <= project_limit
   ```

4. Снова запустите отладчик с breakpoint на этой строке. При значениях
   3 и 3 выражение ошибочно возвращает `True`.
5. Объясните причину: равенство означает, что все места уже заняты.
6. Верните `<`, повторите проверку: результат должен стать `False`.
7. Верните исходные демонстрационные данные `current_load = 2`.
8. Проверьте `git diff`: учебная ошибка не должна попасть в сдаваемый код.

## Основные вопросы по коду

- **Почему три функции?** Они решают разные задачи: сравнение специализаций,
  проверка загрузки и объяснение решения о назначении.
- **Какие типы используются?** `str` для названий и сообщений, `int` для
  загрузки и лимита, `bool` для доступности и результатов проверок.
- **Что возвращает функция решения?** Причину отказа или пустую строку.
  Непустая строка в условии `if` считается истинной.
- **Зачем `strip()` и `casefold()`?** Убирают пробелы по краям и различия
  регистра, чтобы названия можно было сравнить.
- **Почему используется `<`, а не `<=`?** При равенстве загрузки и лимита
  свободных мест нет.
- **Где происходит назначение?** После подтверждения в `main()`:
  заполняется `assigned_manager`, затем увеличивается `current_load`.
- **Что импортируется?** Класс `date` из стандартного модуля `datetime`,
  чтобы вывести дату назначения.
- **Что делает `if __name__ == "__main__"`?** Запускает сценарий только
  при прямом выполнении файла, а не при импорте функций.
- **Зачем `.venv`?** Изолирует инструменты проекта от других окружений.
- **Зачем `.gitignore`?** Исключает окружение, кеши и локальные файлы из Git.
- **Зачем README?** Описывает назначение, сущности, функции, запуск и план.
- **Что сохраняется между запусками?** Пока ничего: JSON появится на ПР2.
